## Install on a Mac

Download the ZIP, then extract its contents into:

`/Users/alirezak/Projects/daily-planner/kids/clothes`

For example:

```bash
mkdir -p /Users/alirezak/Projects/daily-planner/kids/clothes
unzip ~/Downloads/jonna_clothes_wardrobe.zip -d /Users/alirezak/Projects/daily-planner/kids/clothes
```

The Markdown image links are relative to their files and will work after extraction.
